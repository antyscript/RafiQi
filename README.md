# 🚀 RafiQi v2.0.2

**رفيقك في الدراسة (نسخة تجريبية)** – مشروع ويب لحساب المعدل الدراسي وإنشاء منشورات صغيرة للتجربة.  
> ⚠️ **تنبيه:** النسخة التجريبية، المنطق الخلفي غير ثابت بعد، ولا توجد حسابات قوية أو مستخدمون حقيقيون.

---

## 🛠️ التقنيات المستخدمة

- **Frontend:** `HTML`, `CSS`, `JavaScript`, `React`, `React Router DOM`, `MUI`, `Vite`  
- **Backend:** `Node.js`, `Express`, `REST APIs`, `JWT`, `Cookies`, `.env`, `Moment.js`  
- **Database:** `MongoDB`  

> ⚠️ مكتبة Cookies موجودة ضمن المشروع لكنها غير مستخدمة بعد.

---

## ✨ المميزات التجريبية

- 🧮 حساب المعدل الدراسي تلقائياً  
- 📝 إنشاء منشورات بسيطة للتجربة  
- 🎨 واجهة حديثة باستخدام MUI وReact  

> ❌ لا توجد ميزات متقدمة بعد مثل تسجيل المستخدمين أو التفاعل الكامل.

---
